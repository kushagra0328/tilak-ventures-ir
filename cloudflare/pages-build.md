# Cloudflare Pages setup

Connect the GitHub repository `kushagra0328/tilak-ventures-ir` to Cloudflare Pages.

Current site is static HTML/CSS and requires no build command.

- Production branch: `main`
- Build command: leave blank
- Build output directory: `/`
- Root: repository root

After the first deployment, use the Cloudflare Pages-provided preview URL for testing. Only after the site and CMS are fully tested should the company domain be switched from the existing WordPress site.
